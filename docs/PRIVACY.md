# Privacy disclosure draft — not a published privacy policy

This describes the current source only and is not legal advice. A rights holder must review, complete contact/identity, retention, jurisdiction and distribution details, and publish an appropriate policy before release.

The app stores non-secret appearance and main-window screen-protection preferences in app-private Android DataStore. It observes network connectivity status to display it. It declares an Android assistant service that displays an informational panel; recognition reports an error and does not capture audio. There is no implemented provider communication, chat, memory storage, camera, microphone capture, analytics, export or notification listener. Android backup is disabled in the manifest with explicit exclusions; actual OEM behavior has not been verified. The main activity defaults to screen protection, which does not protect all windows or external cameras.

The user can clear app storage in Android settings or uninstall the app to remove local app data, subject to device behavior. Current code does not provide an in-app data export or deletion workflow. The project has no designated privacy contact in this repository. Future integrations must update this disclosure and explain what data is sent, to whom, for what purpose, retention/deletion and consent before use; third-party services operate under their own policies.
